# Implementation Plan: Collapsed Sidebar by Default + Compact Interface

## Current State Analysis
- Sidebar is **always open on desktop** (≥901px) - both `.sidebarOpen` and `.sidebarClosed` use `transform: translateX(0)`
- Mobile (≤900px): sidebar slides in/out via `isMenuOpen` state
- Main wrapper has fixed `margin-left: 240px` (sidebar width)
- No collapsed/compact mode exists
- `isMenuOpen` defaults to `false` (only affects mobile)

## Implementation Approach

### 1. Add Collapsed State Management (Layout.tsx)
- Add new state: `const [isSidebarCollapsed, setIsSidebarCollapsed] = useState(true)` — **collapsed by default**
- Persist state in `localStorage` ('sidebar-collapsed' key)
- Keep `isMenuOpen` for mobile overlay behavior (separate concern)

### 2. Sidebar CSS Changes (Layout.module.css)
**New collapsed sidebar width**: 64px (icon-only, no labels)
- Add `.sidebarCollapsed` class with `width: 64px`
- Hide `.menuLabel`, `.menuGroupTitle`, `.profileCard`, `.sidebarFooter` content when collapsed
- Keep logo visible but abbreviated (e.g., "M" or icon)
- Smooth transition: `transition: width 180ms ease, transform 180ms ease`

**Desktop (≥901px) behavior**:
- `.sidebarClosed` → expanded (240px) when NOT collapsed
- `.sidebarCollapsed` → narrow (64px) when collapsed
- Main wrapper margin: `margin-left: 240px` (expanded) vs `margin-left: 64px` (collapsed)

**Mobile (≤900px)**: Keep existing slide-in/out behavior, ignore collapsed state

### 3. Toggle Button
- Add collapse/expand toggle button in sidebar header (near logo)
- Icon: `chevron-left` / `chevron-right` or `menu` / `x`
- Click toggles `isSidebarCollapsed` state

### 4. Compact Interface Improvements
- Reduce main content padding: `var(--s-5) var(--s-4)` → `var(--s-3) var(--s-3)` 
- Reduce sidebar internal padding: `var(--s-3) 0` → `var(--s-2) 0`
- Tighten menu item padding: `10px 12px` → `8px 10px`
- Reduce menu group gaps: `gap: 10px` → `gap: 6px`
- Dark theme adjustments for compact mode

### 5. Files to Modify
1. `/src/shared/ui/Layout/Layout.tsx` - State, toggle handler, conditional classes
2. `/src/shared/ui/Layout/Layout.module.css` - Collapsed styles, compact spacing, responsive rules

### 6. Key CSS Selectors to Add/Modify
```css
/* Collapsed sidebar */
.sidebarCollapsed { width: 64px; }
.sidebarCollapsed .menuLabel,
.sidebarCollapsed .menuGroupTitle,
.sidebarCollapsed .profileCard,
.sidebarCollapsed .sidebarFooter > *:not(.collapseToggle) { display: none; }
.sidebarCollapsed .logo { /* abbreviated */ }

/* Main wrapper dynamic margin */
.mainWrapper { margin-left: var(--sidebar-width, 240px); }
.mainWrapper.collapsed { --sidebar-width: 64px; }

/* Compact spacing */
.main { padding: var(--s-3) var(--s-3); }
.menuItem { padding: 8px 10px; }
.menu { gap: 6px; }
```

## Questions for Clarification

1. **Collapsed width**: 64px (icon-only) or 72px (with tiny labels)?
2. **Logo in collapsed mode**: Show "M" initial, full "Messenger" hidden, or keep icon only?
3. **Persist preference**: Save to localStorage so it survives refresh? (Recommended: yes)
4. **Compact mode scope**: Apply reduced padding globally or only when sidebar is collapsed?
5. **Animation**: 180ms ease (current) or faster/slower?
